# ResearchOS

ResearchOS is an evidence-grounded multi-agent research system.

It is designed to research complex questions, track evidence and claims, verify sources, handle conflicting information, use research memory, and keep humans involved when judgment is needed.

The project is being built as a production-minded AI engineering system, with reliability and evaluation as first-class concerns.

## Project goals

- Multi-agent research orchestration
- Evidence and claim tracking
- Research memory
- Human-in-the-loop review
- Automated evaluation
- LLM-as-a-judge with human calibration
- Clear observability and failure handling
